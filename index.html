GazeMed in one view

정적인 heatmap에서 판독의 순간으로.

PR #3은 “발화 1.5초 전 시선”이라는 고정 규칙을 학습 가능한 시간 정렬로 바꾸고, 발화의 공간 단어와 실제 시선 좌표를 함께 사용합니다.

01 · Observe

방사선과 의사가 영상을 훑고 소견을 말합니다.

REFLACX는 1,000 Hz gaze, fixation, 단어별 timestamp, 병변 ellipse를 같은 판독 기록에 담습니다.

02 · Align

본 시점과 말한 시점 사이의 지연을 학습합니다.

finding mention 시점과 각 fixation의 signed Δt를 계산하고, 관련 fixation에 둘 attention weight를 학습합니다.

03 · Ground

“left/right”, “upper/lower”, “retrocardiac”을 영상 좌표와 결합합니다.

발화가 주는 방향 제약과 시선이 주는 후보 영역을 합쳐 언급된 이상소견의 위치를 예측합니다.

02 · Data bundle

한 판독 기록을 조립하기

fixation·원시 gaze·발화 timestamp·ellipse·CXR ID가 어떤 key와 좌표계로 연결되는지 확인합니다.

03 · Experiment builder

열린 질문을 판별 실험으로

anatomy prior, causal replay, image–behavior fusion의 비교군·판정 기준·중단 규칙을 바로 설계합니다.

How evidence is built

성능표 앞에 놓이는 네 질문

시선은 정답 그 자체가 아닙니다. 모델이 더 좋아졌다는 주장보다 어떤 정보가 기여했는지 분리하는 실험을 우선합니다.

Signal

무엇을 관찰했나?

좌표, 지속시간, 순서, 발화 시각 중 실제 입력으로 들어간 정보를 명시합니다.

Baseline

무엇보다 나은가?

image-only, fixed-lag, heatmap-only처럼 더 단순한 설명을 먼저 세웁니다.

Ablation

왜 나아졌나?

시간·좌표·공간 단어를 하나씩 제거하거나 섞어 기여를 분리합니다.

Generalize

어디까지 유지되나?

환자·영상·판독자를 분리하고 질환과 병변 크기별 실패를 확인합니다.
