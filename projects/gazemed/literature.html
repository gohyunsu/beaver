Follow the field by input contract.

Two papers may both “use gaze” while solving different problems. The decisive questions are when gaze is available, what the model receives at inference, and what spatial target it predicts.

03

Spatial radiology language is richer than directional keywords.

GazeMed currently uses seven binary location descriptors. This is an interpretable first test, but prior language research already provides a more expressive vocabulary.

Level 1Directional tokens

left · right · upper · lower

Level 2Anatomical entities

heart · hilum · pleura · costophrenic angle

Level 3Relations

behind · adjacent to · above · involving

Level 4Composed frames

finding + anatomical anchor + relation + uncertainty

Rad-SpatialNet represents spatial language as frames containing a trigger and related entities. This suggests a principled extension: make speech produce an anatomy-anchored constraint rather than a flat bag of location bits.

Example

“Small opacity behind the heart” can be represented as finding = opacity, anchor = heart, relation = behind, extent = small. The model can then compare the gaze path with the anchor region and relation—not only with a generic “lower” token.

04

The strongest positioning is narrow and falsifiable.

GazeMed asks Can a simple, finding-conditioned mechanism use a radiologist’s test-time gaze and speech to localize the described abnormality, and can targeted controls identify which parts of that behavior carry the value?

Claims to avoid

  • “The first use of temporal gaze.”Fixation order and gaze–language alignment already appear in prior work.
  • “Gaze is better than the image.”The current models use different inputs; their comparison does not isolate modality superiority.
  • “Real-time localization.”The full-sequence model has not yet passed causal replay.
  • “Spatial language solves grounding.”The current language effect is smaller and weaker on Pointing.

What remains genuinely interesting

The project can contribute a clean test-time behavioral grounding task, a minimal interpretable mechanism, and controls that separate timing, coordinate correspondence, and language content. Its next novelty should come from stronger evidence—not a larger architecture by default.
