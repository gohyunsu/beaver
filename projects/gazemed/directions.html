Evidence priorities

Six questions, ordered by dependency.

Gate 01Incremental value

Does gaze outperform a finding-conditioned anatomy prior?

The finding embedding can encode common locations. Build a prior only from training ellipses and evaluate it on the exact same instances. Report the Final–prior difference by lesion size, chest-center distance, finding, and reader.

Advance if
Final wins overall and shows interpretable gains in predefined subgroups.
Narrow if
Gaze helps only small, peripheral, or anatomically atypical findings.
Gate 02Causal validity

Does the model work without future gaze?

Replay the interpretation in timestamp order. At each mention endpoint, expose only fixations that have already ended. Sweep the available history and report accuracy, coverage, and latency.

Advance if
A causal prefix retains a predefined fraction of full-sequence performance.
Reframe if
Performance depends heavily on post-mention verification gaze.
Gate 03Data validity

Are finding mentions linked correctly?

Stratify a manual audit by finding, negation, uncertainty, repeated mention, and spatial expression. Compare the current regex linker with a clinical relation extractor only after the error profile is known.

Advance if
Linker replacement reduces measured alignment error and improves paired downstream results.
Keep simple if
Most errors do not change timing or descriptors.
Gate 04Generalization

Does the effect survive a new cohort partition and reader?

Repeat the core conditions across multiple patient-grouped splits. Then separate reader transfer from patient transfer with leave-one-reader-out evaluation where data support it.

Advance if
Effect direction and control collapse remain stable across splits.
Adapt if
Reader-specific lag or scan style dominates.
Gate 05Construct

Can diagnostic and verification gaze be distinguished?

Annotate a small, blinded sample around finding mentions for first detection, verification, routine scan, and rejected distractor. Measure inter-rater agreement before training a phase-aware model.

Advance if
The roles are annotatable and generalize across readers.
Remain latent if
Role labels cannot be defined reliably from the record.
Gate 06Complementarity

Do image and behavior fail on different cases?

Join per-instance RadZero and Final outputs. Measure error correlation and the oracle ceiling before training fusion. Test calibrated averaging before any joint architecture.

Advance if
A simple validation-calibrated fusion beats both inputs across splits.
Stop if
The oracle ceiling is too small to justify a larger model.

03

Develop spatial language as a structured research program.

The current seven binary descriptors are a useful diagnostic probe. The strongest extension is not simply a larger text encoder; it is a representation that connects a finding to anatomy and a relation.

Stage A

Audit the current tokens

Measure coverage, precision, co-occurrence, left/right consistency, and contribution by descriptor.

Question · Which words carry signal now?
Stage B

Add anatomical anchors

Extract heart, hilum, pleura, lung zones, mediastinum, and costophrenic angles.

Question · Does language identify a region before gaze?
Stage C

Represent relations

Encode behind, adjacent to, involving, above, below, and bilateral compositions as frames.

Question · Can relations disambiguate competing fixations?
Stage D

Calibrate uncertainty

Separate positive, uncertain, negated, and comparative statements rather than dropping them into one mention.

Question · When should the model abstain?
Recommended first extension

Use an interpretable anatomy-relation frame before an unrestricted sentence encoder. It provides explicit coverage and failure analysis, and can later serve as supervision for a learned text representation.

Conditional expansion

Combine modalities only after proving complementarity.

Image evidence and interpretation behavior answer different questions. Their combination should proceed from analysis to simple calibration, not directly to a joint transformer.
