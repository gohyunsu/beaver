Chapter 02 · Data

One reading, assembled from synchronized traces.

REFLACX joins a chest X-ray reading with gaze, word timestamps, labels, and localization ellipses. Understanding that join is part of the model.

In this chapter 1. What REFLACX contains 2. The file bundle 3. Building an instance 4. Space and time 5. Labels and phases 6. Split and access rules

01

REFLACX records interpretation, then adds validation labels.

Five radiologists interpreted frontal chest X-rays while an EyeLink 1000 Plus recorded gaze and a microphone recorded dictation. The transcript was aligned to time. After interpretation, radiologists selected findings and drew ellipses for localizable abnormalities.

3,032synchronized gaze–report readings
2,616unique chest X-rays
2,199unique subjects
5radiologists
Two moments of evidence

Gaze and dictation are traces produced during interpretation. Ellipses and certainty scores are later validation annotations. They should not be treated as if they were collected at the same cognitive moment.

02

A reading is a folder, not a row.

Each reading ID names a bundle of files. GazeMed must join them before it can form a single finding-level example.

Start/end time, mean image position, duration, pupil, and display state.

1,000 Hz coordinates and pupil measurements, including missing rows around blinks.

Corrected transcript tokens with word start and end times.

anomaly_location_ellipses.csvReference regions

Ellipse extremes, certainty, and one or more finding columns.

A box around lungs and heart for chest-relative normalization.

metadata_phase_*.csvIdentity and labels

Reading, DICOM, subject, image size, quality flags, and image-level certainty.

The raw image is linked through the DICOM identifier to MIMIC-CXR. Restricted source files are not part of this website or its repository.

A practical instance-construction sequence

  1. 1
    Choose an eligible reading.

    Require usable gaze, transcript, image dimensions, and the selected collection phase.

  2. 2
    Identify a positive finding.

    Apply the predefined certainty rule and label crosswalk.

  3. 3
    Link the finding to speech.

    Find its mention while handling negation, uncertainty, synonyms, and repeated mentions.

  4. 4
    Attach candidate fixations.

    Compute each fixation’s temporal relation to the chosen mention.

  5. 5
    Construct the target map.

    Rasterize the matching ellipse or ellipses only for evaluation and supervision.

Current weak link

PR #3 uses a rule-based mention linker. Its errors affect timing and language features at the same time, so a manual audit is a high-value validation step.

04

Every coordinate and timestamp needs an explicit frame.

REFLACX pixel coordinates use the top-left image origin: x increases to the right and y increases downward. Timestamp columns are measured in seconds from the beginning of the audio recording.

Coordinate audit

Screen → image

Verify zoom, pan, windowing, display offsets, image size, and chest-relative normalization with visual samples.

Time audit

Tracker → audio

Verify synchronization messages, word timestamp interpolation, fixation start/end conventions, and unit conversions.

Quality audit

Missing → invalid

Quantify blink intervals, missing pupil values, recording duration, fixation count, and discarded recordings.

05

Label vocabulary changes across collection phases.

REFLACX was collected in three phases. Phase 1 used several narrower labels; Phases 2 and 3 merged some of them. GazeMed currently uses Phase 3, the main collection phase with 2,507 readings.

Earlier wordingPhase 2–3 wording

Certainty is not a binary truth

Image-level and ellipse annotations use a 0–5 certainty scale. Zero means the label was not selected; values 1–5 move from unlikely to consistent with. Any conversion to positive/negative examples needs a predefined threshold and sensitivity analysis.

An ellipse is a reference region.

Its size reflects the annotation interface and the radiologist’s judgment, not necessarily a histologically precise boundary. IoU must be interpreted with that coarseness in mind.

06

The evaluation split must follow the entity structure.

A patient-level split is the minimum requirement. Readings of the same image must remain together. Because the same five radiologists may appear on both sides of a patient split, reader generalization remains a separate question.

Keep togetherpatient · study · image · repeated readings
Measure separatelynew patient · new reader · new institution
Never exposetest ellipses · test label locations · restricted raw data

Access and provenance

REFLACX and MIMIC-derived files require credentialed access and data-use compliance. The public project should contain preprocessing code, schemas, synthetic fixtures, and reproducible split rules—not the source images, gaze recordings, or reports.
