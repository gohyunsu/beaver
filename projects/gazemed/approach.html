GazeMed/Approach

Chapter 03 · Approach

Replace a fixed rule with learned relevance.

The architecture is intentionally small. Each step adds a specific information source so that its contribution can be isolated.

In this chapter 1. Fixed-lag baseline 2. Learned timing 3. Position and language 4. Spatial output 5. Training and controls 6. Inference boundary

01

Baseline: take gaze from 1.5 seconds before the mention.

The original REFLACX label-specific heuristic assumes that gaze shortly before a finding is spoken is likely to correspond to that finding. It gives every case the same temporal rule.

−3 s−1.5 smention
discardselected gaze windowspeech

The baseline is valuable because it is simple, interpretable, and connected to prior work. Its limitation is equally clear: radiologists do not all speak with the same delay, and the delay may differ across findings within the same reading.

Reference point

The site reports the team’s re-evaluation of this heuristic on the PR #3 instance set—not the final score of the original published model.

02

V1: learn the temporal association for every fixation.

For a finding mention at time tm, the model computes a feature vector for each fixation. These features describe when the fixation occurred and how it moved, without exposing its x/y position to the attention mechanism.

1signed Δtfixation time − mention time
2|Δt|absolute temporal distance
3before indicatorwhether gaze precedes the mention
4legacy-window indicatorwhether the fixation falls in the fixed rule
5durationhow long the fixation lasts
6velocitydisplacement from the preceding fixation over time

An 8-dimensional finding embedding is added because the relevant timing may differ by finding. A small network produces one score per fixation, then a softmax converts those scores into a relevance distribution.

6 temporal / kinematic features+finding embedding→attention over fixations
What “temporal-only” means

The model cannot use x/y to decide attention. After attention is computed, the selected weights are still placed at the real fixation positions to form a localization map.

The language representation is deliberately interpretable, but coarse. It does not parse anatomical relations, compositional phrases, negation scope, or uncertainty. Those limits define the next language experiments.

04

The model can only place mass where the radiologist looked.

There is no learned image decoder. Each attention weight is splatted at its fixation’s real x/y coordinate, spread with a Gaussian kernel, and normalized into a probability map.

This restriction makes the output easy to interpret and makes position-shuffling a meaningful test: if the correspondence between a fixation’s features and its coordinate is broken, performance should fall.

05

Train attention to place probability mass inside the ellipse.

The loss rewards attention mass that lands inside the target region, with a small entropy term. Validation selects the map threshold and smoothing bandwidth; test evaluation keeps them fixed.

Comparison A

Fixed rule → learned timing

Tests whether a learned temporal association improves on one shared lag.

Comparison B

Temporal → final

Tests the joint addition of position-aware attention and language descriptors.

Control C

Shuffle fixation positions

Breaks each fixation’s feature-to-coordinate pairing while preserving the aggregate coordinate set.

Control D

Mask spatial words

Zeros only the seven spatial descriptors in the trained final model.

Why the controls answer different questions

Position shuffling tests whether the model uses true instance-level spatial correspondence rather than only capacity or aggregate gaze shape. Spatial-word masking tests whether report language contributes location information beyond the finding label.

Reproducibility

Both weight initialization and example order must be seeded. Small order changes are large enough to alter the significance of the weaker language control.

06

Test-time input is established; causal streaming is not.

The current model consumes gaze and speech for each new reading, which distinguishes it from methods that use gaze only to train an image-only model. However, it receives the full fixation sequence and uses signed time offsets. Future fixations are therefore candidates unless explicitly masked.

Current evidenceoffline, test-time gaze + speech localization
≠
Future claimcausal, low-latency streaming localization

A causal replay must reveal events in timestamp order, emit a map at a defined output clock, prevent any fixation ending after that clock from entering the model, and report both latency and cases with insufficient gaze history.
