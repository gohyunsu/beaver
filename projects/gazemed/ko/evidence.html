GazeMed/근거

4장 · 근거

모든 수치는 그 비교 대상과 함께 읽는다.

핵심 결과는 최고 점수 하나가 아니다. 시간, 좌표, 공간 언어가 실제 정보를 제공하는지 단계별 비교로 확인하는 데 있다.

이 장의 구성 1. 평가 지표 2. 결과표 3. 지지되는 주장 4. 정보 대조 실험 5. 외부 모델 비교 6. 근거의 경계

01

IoU와 Pointing은 서로 다른 위치 추정 질문에 답한다.

Intersection-over-Union
면적(예측 ∩ 목표) / 면적(예측 ∪ 목표)

영역 전체가 얼마나 겹치는지 본다. 임계값, smoothing, 목표 크기와 지도의 퍼짐에 민감하다.

Pointing game
예측 최댓값이 목표 안이면 1, 아니면 0

가장 확신하는 한 점이 타원을 맞히는지 묻는다. 나머지 지도의 품질은 평가하지 않는다.

같은 변화가 IoU만 높이고 Pointing은 그대로 둘 수도 있다. 예측 영역이 타원과 더 잘 겹치더라도 최고점이 경계의 같은 쪽에 남을 수 있기 때문이다. 그래서 두 지표를 함께 읽어야 한다.

03

현재 근거는 서로 다른 강도의 세 주장을 지지한다.

주장 1 · 강함

위치 인식·언어 조건부 주의가 시간 정렬만 쓴 모델보다 낫다.

최종 모델은 학습 seed 5개와 환자 분할 5개 모두에서 두 지표가 시간 전용 모델보다 높다. seed 평균 이득은 IoU +0.0303, Pointing +0.1241이다.

주장 2 · 강함

향상은 응시 특징과 실제 위치의 올바른 대응에 의존한다.

인스턴스 안에서 좌표만 순열화하면 서로 다른 seed·분할 실행 9개 모두에서 두 지표가 유의하게 하락한다. 좌표 집합은 남아 있지만 시간·언어 맥락과 좌표의 짝이 끊어진 결과다.

주장 3 · 현재 프로토콜 안에서 강함

공간 단어는 시간, 위치, 소견 이름을 넘어 추가 정보를 준다.

공간 표현 7개를 가리면 9/9 실행에서 두 지표가 모두 유의하게 내려간다. seed 평균 하락은 IoU 0.0317, Pointing 0.0567이다.

04

Ablation은 부품을 빼고, control은 대안 설명을 시험한다.

PR #3의 두 대조 실험은 학습된 모델 대부분을 유지한 채 평가 시점의 특정 정보만 손상한다. 따라서 단순 성능 비교보다 어떤 설명이 맞는지 더 직접적으로 묻는다.

05

RadZero는 경쟁력 있는 참조점이지, 어느 modality가 더 낫다는 판정은 아니다.

RadZero는 영상 patch와 문구로 위치를 찾고, GazeMed Final은 영상 픽셀 없이 시선과 음성으로 찾는다. 동일한 1,093개 예제에서 RadZero에 지표별 최적 설정을 허용해도 Final이 두 지표에서 더 높다.

RadZero영상 + 문구

CXR 자체가 시각 증거를 직접 제공한다.

최고 IoU 0.3165 · 최고 Pointing 0.7255
vs
GazeMed Final시선 + 음성

판독자의 행동이 시각 증거를 매개한다.

IoU 0.3399 · Pointing 0.7941

입력 계약이 서로 다르므로 이 비교는 행동 기반 모델이 현재 프로토콜에서 경쟁력이 있음을 보여줄 뿐, 시선이 영상보다 우수한 정보원임을 보여주지 않는다. 외부 기준선은 한 환자 분할에서만 평가되었고 두 모델의 오류가 상보적인지도 아직 열려 있다.

짝지은 비교

Final − RadZero: IoU +0.0234, p = 4.4×10⁻⁸; Pointing +0.0686, p = 4.9×10⁻⁵. RadZero의 두 최적값은 서로 다른 operating point다.

06

관찰한 것, 지지되는 것, 아직 열린 것을 분리한다.

관찰
  • 주 환자 분할의 1,093개 예제
  • 학습 seed 5개와 환자 분할 5개
  • 9/9 실행의 위치·언어 대조 실험
  • 주 분할에서의 RadZero 일치 평가
지지
  • 학습된 시간이 고정 지연보다 우수함
  • 실제 응시 좌표를 사용함
  • 공간 단어가 두 지표에 기여함
  • 행동 전용 위치 추정이 이 조건에서 경쟁력 있음
열린 질문
  • 인과적 실시간 성능
  • 새 판독자·장비·기관으로의 전이
  • 해부학 prior를 넘는 가치
  • 임상 언급 연결 정확도
  • 기관·장비 간 보정 강건성
예비 결과를 읽는 원칙

다섯 환자 분할은 표본 선택 민감도를, 다섯 seed는 최적화 민감도를 측정한다. 전자의 IoU 변동이 5.6배 더 크다. 하지만 모두 같은 REFLACX 풀에서 나온 표본이므로 다른 판독자 집단, 기관, 스캐너 구성이나 시선 장비로의 전이를 증명하지는 않는다.
