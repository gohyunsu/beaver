GazeMed/접근법

3장 · 접근법

고정 규칙을 학습된 관련성으로 바꾼다.

모델은 의도적으로 작게 설계되었다. 한 단계마다 새로운 정보원 하나를 더해, 시간·좌표·언어가 각각 무엇을 기여하는지 비교할 수 있다.

이 장의 구성 1. 고정 지연 기준선 2. 학습된 시간 정렬 3. 위치와 언어 4. 공간 출력 5. 학습과 대조 실험 6. 추론 범위

01

기준선: 소견을 말하기 1.5초 전의 시선을 선택한다.

REFLACX의 기존 소견별 휴리스틱은 의사가 이상을 먼저 보고 잠시 뒤 말한다는 가정에서 출발한다. 따라서 소견이 언급된 시각보다 1.5초 앞선 구간의 시선을 해당 소견과 연결한다.

−3초−1.5초언급
제외선택된 시선 구간발화

이 기준선은 단순하고 해석 가능하며 선행 연구와 직접 연결된다. 동시에 모든 판독자·소견·문장에 같은 지연을 강제한다. 실제로는 보고 말하기까지의 시간이 사람과 맥락에 따라 달라진다.

비교의 기준

여기서 보고하는 점수는 원 논문의 최종 모델 점수가 아니라, PR #3의 동일 예제 집합에서 이 휴리스틱을 다시 평가한 결과다.

02

V1: 모든 응시에 대해 발화와의 시간 관계를 학습한다.

소견이 언급된 시각을 tm이라 하면, 각 응시는 언급과의 시간차와 움직임을 나타내는 특징 벡터가 된다. 이 단계의 주의 점수는 x/y 위치를 보지 않는다.

1부호 있는 Δt응시 시각 − 언급 시각
2|Δt|절대 시간 거리
3선행 여부응시가 언급보다 앞서는가
4기존 창 포함 여부1.5초 규칙 안에 드는가
5응시 지속 시간한 지점에 머문 시간
6속도이전 응시로부터의 이동량 / 시간

여기에 8차원 소견 임베딩을 붙여 소견별 시간 패턴 차이를 표현한다. 작은 신경망이 응시마다 점수 하나를 만들고, softmax가 전체 점수를 합이 1인 관련성 분포로 바꾼다.

시간·운동 특징 6개+소견 임베딩→응시별 주의 확률
‘시간만 사용’한다는 뜻

주의 가중치를 정할 때 x/y를 보지 않는다는 뜻이다. 가중치를 지도에 놓을 때는 실제 응시 좌표가 필요하므로, 최종 출력은 여전히 공간 지도다.

03

최종 모델: 언어가 ‘어느 위치의 응시가 관련 있는가’를 묻는다.

최종 모델은 각 응시의 key에 Fourier 위치 표현을, 하나의 query에 소견과 보고서의 공간 표현을 넣는다. 한 층의 scaled dot-product cross-attention이 query와 모든 key의 관련성을 계산한다.

Query · 투영 전 18차원

무엇을 어디에서 찾는가?

  • 8차원 학습 소견 임베딩
  • 공간 표현 7개: left, right, bilateral, upper, lower, middle, retrocardiac
  • 범위 표현 3개: 작은 형태, 큰 형태, 미만성 형태
주의를
계산
Keys · 응시마다 하나

어느 시선 점이 관련 있는가?

  • 시간·운동 특징 6개
  • 정규화한 x/y의 다중 주파수 sin/cos 표현
  • 응시 유효성 마스크

이 언어 표현은 작은 규칙 기반 어휘다. 자유문장 임베딩보다 무엇을 사용했는지 분명하지만, 해부학적 관계, 부정 범위, 불확실성, 복합 지시 표현을 충분히 다루지는 못한다.

구현에서 발견된 중요한 세부 사항

현재 소스는 소견 임베딩을 모든 key에도 연결하지만, 모든 응시에 똑같이 더해지는 항은 softmax에서 상쇄된다. 소견 정체성은 query를 통해 실질적으로 작동한다. 다음 구현에서는 이 불필요한 key 항을 제거해 코드와 설명을 일치시키는 편이 타당하다.

왜 Fourier 위치 표현을 쓰는가

원시 x/y에 선형 투영 하나만 적용하면 위치에 대한 선형 함수만 만들 수 있다. 여러 주파수의 sin/cos는 좌표를 더 풍부한 기저로 올려, 언어 query가 ‘왼쪽 위’처럼 비선형적인 영역을 선택하게 한다. 완전한 2×2 비교에서 cross-attention + Fourier는 0.3391 IoU / 0.7993 Pointing, cross-attention + 원시 좌표는 0.3198 / 0.7204다. 다만 결합 MLP에서는 같은 Fourier 이득이 나타나지 않으므로, 핵심은 표현과 결합 방식의 상호작용이다.

04

모델은 판독자가 실제로 본 곳에만 확률 질량을 놓을 수 있다.

학습된 영상 디코더는 없다. 각 주의 가중치를 해당 응시의 실제 x/y에 놓고, Gaussian 커널로 퍼뜨린 뒤 합이 1인 확률 지도로 정규화한다.

가중된 점
→
Gaussian 확산
→
임계값 지도

이 제약 덕분에 출력의 근거를 쉽게 추적할 수 있다. 또한 각 응시의 특징과 좌표를 뒤섞는 대조 실험이 의미를 갖는다. 올바른 대응이 중요하다면 뒤섞었을 때 성능이 떨어져야 한다.

05

타원 안에 주의 확률이 모이도록 학습한다.

손실 함수는 목표 타원 내부에 놓인 주의 질량을 보상하고, 작은 엔트로피 항으로 분포를 조절한다. 지도 임계값과 smoothing bandwidth는 검증 집합에서 고른 뒤 시험 집합에서는 고정한다.

비교 A

고정 규칙 → 학습된 시간

하나의 공통 지연보다 사례별 시간 관련성을 학습하는 것이 나은지 묻는다.

비교 B

시간 모델 → 최종 모델

위치 인식 주의와 언어 표현을 함께 더한 효과를 측정한다.

대조 C

응시 위치 섞기

전체 좌표 집합은 보존하되 각 특징과 실제 좌표의 짝을 끊는다.

대조 D

공간 단어 가리기

학습된 최종 모델에서 일곱 공간 표현만 0으로 만든다.

두 대조 실험은 서로 다른 설명을 검증한다

위치 섞기는 단순한 모델 용량이나 평균 시선 형태가 아니라 사례별 특징–좌표 대응을 사용하는지 본다. 공간 단어 가리기는 보고서가 소견 이름을 반복하는 것 이상으로 위치 정보를 주는지 본다.

재현성

가중치 초기화와 예제 순서를 모두 고정해야 한다. 현재 결과는 다섯 학습 seed와 다섯 환자 분할을 따로 보고한다. 환자 분할 변화가 IoU에 더 큰 변동을 만든다.

06

시험 시 시선·음성을 쓰는 것은 확인했지만, 인과적 실시간 추론은 아직 아니다.

현재 모델은 새 판독의 시선과 발화를 입력으로 사용한다. 학습 때만 시선을 쓰고 추론 때는 영상만 보는 방법과 구별되는 지점이다. 그러나 전체 응시 시퀀스와 부호 있는 시간차를 받기 때문에, 명시적으로 가리지 않으면 발화 이후의 응시도 후보가 된다.

현재 근거오프라인 · 시험 시 시선 + 음성 위치 추정
≠
향후 주장인과적 · 저지연 스트리밍 위치 추정

실시간을 주장하려면 사건을 시간순으로 공개하고, 출력 시계를 명시하며, 그 시각 이후에 끝난 응시를 차단해야 한다. 지연 시간과 아직 충분한 시선 이력이 없어 출력을 못 하는 사례도 함께 보고해야 한다.
