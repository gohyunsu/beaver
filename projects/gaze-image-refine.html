Research gap

“보았다”와 “고치고 싶다” 사이의 간극

텍스트 프롬프트만으로 원하는 이미지를 반복 생성하면, 사용자는 이상한 손·잘못된 개수·어긋난 배치처럼 시각적으로 바로 느끼는 문제를 다시 언어로 옮겨야 합니다. 그러나 gaze를 곧바로 의도로 해석하면 시각적으로 현저하지만 만족스러운 영역도 잘못 건드립니다. 이것이 gaze interaction의 고전적인 Midas touch 문제입니다.

novelty 경계

GazeGen은 사용자가 바라본 객체를 능동적 편집 대상으로 사용합니다. Eye Want It All!은 16명 연구에서 재생성하고 싶은 영역을 더 오래 본다는 상관을 보였습니다. 따라서 본 연구는 gaze-controlled editing 자체가 아니라 passive dissatisfaction inference의 식별 가능성과 오류 통제를 입증해야 합니다.

gaze는 visual saliency와 prompt–image mismatch를 통제한 뒤에도 사용자가 실제 선택할 edit region을 예측하는가?

어떤 오류 유형·공간 범위·현저성 조건에서 gaze가 유용하고, 언제 모호한가?

gaze-assisted suggestion은 false interruption을 통제하면서 수정 시간·언어화 부담을 줄이는가?

Study 1 · 측정 가능성을 먼저 검증

시스템 효과를 보기 전에, gaze가 edit intent를 얼마나 식별할 수 있는지 검증합니다. 같은 trial 안에서 사전 관찰 gaze → 명시적 keep/edit 결정 → edit region mask/box → 수정 instruction → 최종 선택 순서를 보존하면 사후 행동을 reference label로 사용할 수 있습니다.

Study 2 · 예측이 아니라 도움의 가치

Study 1에서 calibrated precision과 spatial accuracy가 기준을 넘을 때만 시스템 평가로 진행합니다. 자동으로 편집하지 않고, 모델이 높은 확신을 가질 때 “이 영역을 수정할까요?”라는 preview를 제공하고 사용자가 승인·수정·무시하게 합니다.

Baseline UI

텍스트 instruction + 수동 영역 지정. 현재 generative inpainting workflow를 대표합니다.

Gaze-assisted UI

상위 1–3개 region candidate와 추정 이유를 보여주되, explicit confirmation 전에는 아무것도 변경하지 않습니다.

Outcome

  • 효율: time-to-first-valid-edit, 총 수정 시간, prompt revision 수, region 지정 동작 수.
  • 정확성: suggestion precision, accepted suggestion rate, false interruption rate, correction quality blind rating.
  • 경험: NASA-TLX, perceived control, trust calibration, annoyance, privacy concern.
  • 행동: suggestion 수정·무시·되돌리기, manual override, gaze candidate 확인 시간.

윤리와 해석 경계

  • gaze는 생체·행동 데이터이며 취향, 인지 상태, 건강 정보에 대한 과도한 추론 가능성이 있습니다. 연구 목적·보관 기간·2차 이용 범위를 명시합니다.
  • raw eye video가 필요하지 않다면 gaze coordinates만 보관하고, participant ID는 별도 키로 분리합니다.
  • 수정 제안은 자동 실행하지 않고 explicit confirmation과 undo를 제공합니다.
  • “불만족을 읽는다”보다 “후속 edit 행동을 예측한다”라고 operationalize합니다.
  • 시선 정확도와 calibration 품질이 낮은 참가자를 배제하는 기준을 사전 정의하고, 배제 규모를 보고합니다.
