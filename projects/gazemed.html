Concept primer · 01

시선 데이터는 점들의 목록이 아닙니다.

eye tracker가 측정한 원시 좌표는 눈의 움직임을 해석한 결과가 아닙니다. 분석 단위가 바뀔 때 보존되는 정보와 버려지는 정보도 달라집니다.

(x, y, t)와 pupil·window 상태입니다. REFLACX raw gaze는 초당 1,000회 기록되지만 결측, blink, calibration 오차도 포함합니다.

04 · Scanpath

사건의 순서

fixation을 시간순으로 연결합니다. 같은 heatmap이라도 “병변을 먼저 발견한 경우”와 “나중에 재확인한 경우”를 구분합니다.

보존: order · 과제: 길이와 개인차
시선 ≠ 병변

정상 구조 확인, 탐색, 재검토, 놀람도 fixation을 만듭니다. 따라서 gaze는 병변의 정답 mask가 아니라 후보 위치를 좁히는 noisy evidence로 다뤄야 합니다.

Concept primer · 02

흉부 X-ray의 방향어는 환자 기준입니다.

정면 흉부 X-ray는 환자와 마주 보는 것처럼 표시됩니다. 따라서 영상의 왼쪽은 대개 환자의 오른쪽입니다. “right lower lung”, “left base”, “above the hilum” 같은 발화는 단순한 단어가 아니라 영상 좌표를 제한하는 관계입니다.

lateralityleft · right · bilateral

환자 기준 좌우. 영상 표시 방향과 혼동하면 좌표가 수평 반전됩니다.

verticalupper · mid · lower · base · apex

절대 pixel 값보다 lung/chest box 안의 상대 위치로 정규화하는 편이 견고합니다.

relationabove · below · adjacent · behind

두 anatomy 사이의 관계이므로 단일 분류 token보다 구조화된 제약이 필요합니다.

projectionAP · PA

촬영 방향에 따라 심장 확대와 구조 겹침이 달라집니다. projection을 보조 변수로 둡니다.

이 페이지는 모델링에 필요한 영상 좌표·언어 개념만 다룹니다. 임상 판독 지침이 아닙니다.

B0 · Heuristic

1.5초 전 gaze

발화 직전의 고정 구간을 합쳐 위치를 추정합니다. 단순하고 해석 가능하지만 개인·구절별 지연을 표현하지 못합니다.

M1 · Temporal

lag를 데이터에서 학습

실제 좌표 의미를 제한한 채 gaze–speech 타이밍만으로 대응 구간을 선택해 시간 정렬 자체의 가치를 봅니다.

좌표와 방향어 결합

Preliminary evidence

현재 결과는 방향을 고르는 증거입니다.

PR #3에 보고된 결과에서 학습 기반 temporal alignment가 고정 규칙보다 높고, 실제 gaze 좌표와 발화의 공간 표현을 추가했을 때 다시 개선되었습니다. 이는 다음 실험을 진행할 근거지만, 최종 성능 주장을 하기에는 split·seed·신뢰구간·ablation 검증이 더 필요합니다.

Implementation direction

다음 모델은 더 크기보다 더 분해 가능하게.

PR #3의 강점인 온라인 정렬을 유지하면서 무엇이 성능을 만드는지 드러나는 구조가 가장 효율적입니다.

Recommended architecture

Streaming Phrase–Gaze Grounder

판독이 진행되는 동안 완성된 구절만 감지하고, 그 시점 이전의 fixation에서 후보를 가져온 뒤, 공간 언어와 anatomy 좌표를 결합합니다. 이미지 전체를 매번 재인코딩하지 않고 CXR feature를 한 번 cache합니다.

1Phrase trigger소견·방향 구절이 완성되는 시점 감지
→
2Soft lag retrieval과거 K초 fixation에 확률 가중치 부여
→
3Anatomy grounding좌우·상하·관계 표현을 좌표 prior로 변환
→
4Region + confidence후보 heatmap과 보류 가능한 신뢰도 출력
Module A

구절 단위 trigger

모든 단어마다 위치를 예측하지 않고 pathology mention이나 공간 구절이 완성될 때만 grounding합니다.

  • CheXpert-style finding lexicon + anatomy/spatial lexicon으로 첫 baseline
  • “no”, “without” 같은 negation과 uncertainty를 별도 속성으로 보존
  • word timestamp 보정 오차를 고려해 phrase 끝 주변에 tolerance 부여
Module B

다중 시간척도 soft lag

하나의 최적 lag를 고르지 않고 여러 과거 구간에 attention을 분배합니다.

  • 0–0.5, 0.5–1, 1–2, 2–4초의 causal fixation bank
  • duration·saccade gap·phrase embedding으로 attention weight 계산
  • 미래 gaze를 보지 못하도록 causal mask를 강제
Module C

anatomy-normalized coordinates

원시 pixel보다 chest/lung box 안의 상대 좌표를 함께 사용해 영상 크기와 확대 상태 차이를 줄입니다.

  • screen → displayed image → original image 좌표 변환을 먼저 검증
  • AP/PA와 patient laterality를 명시적 feature로 입력
  • zoom·pan 변화가 있는 fixation은 당시 viewport로 역변환
Module D

보류할 수 있는 출력

gaze와 language가 충돌하거나 근거가 약하면 억지로 병변을 표시하지 않습니다.

  • region confidence와 no-grounding probability를 함께 출력
  • gaze–phrase agreement를 별도 auxiliary score로 학습
  • risk–coverage curve로 “얼마나 자주 답할지” 결정
가장 먼저 확인할 ceiling

실제 병변과 겹치는 fixation만 oracle로 골랐을 때도 IoU가 낮다면, alignment 모델보다 gaze 자체의 공간 해상도와 ellipse 차이가 병목입니다. 이 경우 복잡한 모델을 키우기 전에 task를 point/containment 중심으로 재정의해야 합니다.

Time

lag shuffle

phrase와 다른 record의 시간차를 섞었을 때 성능이 유지되면 temporal alignment 주장은 약합니다.

Space

coordinate permutation

fixation 좌표를 영상 안에서 섞어도 같다면 실제 시선 위치가 아니라 다른 단서가 작동합니다.

Language

spatial token mask

left/right/top/below를 지워 M2와 M3의 차이가 언어 공간 제약에서 오는지 확인합니다.

Causality

future-gaze leak test

발화 뒤 gaze를 사용할 때만 좋아지면 online 추론 결과로 주장할 수 없습니다.

분할과 통계

  • 동일 subject_id·dicom_id가 train/test를 넘지 않는 patient/image group split
  • 가능하면 reader-held-out 결과를 별도로 보고해 개인화 의존성 확인
  • 동일 case에 대한 모델별 paired bootstrap CI와 permutation test
  • 질환, 병변 크기, certainty, 판독자별 subgroup 결과

완료 기준

  • PR #3 결과를 고정 manifest·split·seed에서 재현
  • IoU뿐 아니라 Pointing, containment, center distance를 함께 보고
  • 20개 이상 overlay를 수동 감사해 좌우 반전·zoom/pan 좌표 오류 제거
  • 고정 lag와 동일하거나 낮으면 복잡도 확대 전에 error taxonomy 작성

Failure modes

좋은 점수처럼 보이는 다른 이유들

멀티모달 정렬에서는 모델 구조보다 시간 누출, 좌표 변환, 언어 shortcut이 결과를 더 크게 만들 수 있습니다.

R1 · Temporal leakage

미래 시선을 사용함

offline 전체 record를 입력하면 아직 말하지 않은 뒤쪽 gaze가 정답을 알려줄 수 있습니다.

Guardrail · causal mask + timestamp assertion
R2 · Coordinate mismatch

screen과 image 좌표가 어긋남

zoom, pan, windowing 시 원시 화면 좌표를 영상 pixel로 착각하면 overlay가 조용히 틀어집니다.

Guardrail · viewport inverse mapping + visual audit
R3 · Text shortcut

“right”만으로 위치를 맞힘

gaze 없이도 방향 단어가 큰 영역을 제한합니다. 개선을 gaze 효과로 잘못 읽을 수 있습니다.

Guardrail · language-only + gaze-shuffled baseline
R4 · Reader memorization

개인 lag 패턴을 외움

같은 판독자가 양쪽 split에 있으면 일반적 alignment가 아니라 reader style을 기억할 수 있습니다.

Guardrail · reader-held-out supplementary test
