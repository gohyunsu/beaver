Concept primer · 01

시선 데이터는 점들의 목록이 아닙니다.

eye tracker가 측정한 원시 좌표는 눈의 움직임을 해석한 결과가 아닙니다. 분석 단위가 바뀔 때 보존되는 정보와 버려지는 정보도 달라집니다.

01 · Sample

한 시점의 측정값

(x, y, t)와 pupil·window 상태입니다. REFLACX raw gaze는 초당 1,000회 기록되지만 결측, blink, calibration 오차도 포함합니다.

보존: dwell · 손실: saccade 안의 세부 궤적
03 · Heatmap

공간 밀도의 요약

보존: where · 손실: when, order
04 · Scanpath

사건의 순서

fixation을 시간순으로 연결합니다. 같은 heatmap이라도 “병변을 먼저 발견한 경우”와 “나중에 재확인한 경우”를 구분합니다.

보존: order · 과제: 길이와 개인차
시선 ≠ 병변

정상 구조 확인, 탐색, 재검토, 놀람도 fixation을 만듭니다. 따라서 gaze는 병변의 정답 mask가 아니라 후보 위치를 좁히는 noisy evidence로 다뤄야 합니다.

Concept primer · 02

흉부 X-ray의 방향어는 환자 기준입니다.

정면 흉부 X-ray는 환자와 마주 보는 것처럼 표시됩니다. 따라서 영상의 왼쪽은 대개 환자의 오른쪽입니다. “right lower lung”, “left base”, “above the hilum” 같은 발화는 단순한 단어가 아니라 영상 좌표를 제한하는 관계입니다.

lateralityleft · right · bilateral

환자 기준 좌우. 영상 표시 방향과 혼동하면 좌표가 수평 반전됩니다.

verticalupper · mid · lower · base · apex

절대 pixel 값보다 lung/chest box 안의 상대 위치로 정규화하는 편이 견고합니다.

relationabove · below · adjacent · behind

두 anatomy 사이의 관계이므로 단일 분류 token보다 구조화된 제약이 필요합니다.

projectionAP · PA

촬영 방향에 따라 심장 확대와 구조 겹침이 달라집니다. projection을 보조 변수로 둡니다.

이 페이지는 모델링에 필요한 영상 좌표·언어 개념만 다룹니다. 임상 판독 지침이 아닙니다.

Preliminary evidence

현재 결과는 방향을 고르는 증거입니다.

PR #3의 최신 technical spec은 B1, RadZero, Temporal-only, Final과 두 information-removal control을 같은 1,093개 test instance에서 평가합니다. Final은 Temporal-only와 B1보다 높고, 외부 image-text 모델 RadZero보다 IoU는 높으며 Pointing은 통계적으로 동률입니다.

예측 영역과 reference ellipse가 얼마나 겹치는지 봅니다. 작은 병변에는 위치가 조금만 빗나가도 크게 감소합니다.

Pointing예측 peak ∈ reference region

가장 강한 예측점이 병변 안에 들어가는지 봅니다. 영역의 크기·모양 품질은 충분히 평가하지 못합니다.

현재 읽을 수 있는 결론

시간만 사용하는 attention보다 위치·언어를 함께 사용한 attention이 낫고, position shuffle 붕괴는 실제 fixation↔position 대응이 효과를 만든다는 강한 근거입니다. 공간 단어 효과는 IoU에서 5/5 seed 유지되지만 Pointing에서는 2/5 seed만 유의하므로 더 약하게 주장해야 합니다.

Implementation direction

다음 모델은 더 크기보다 더 분해 가능하게.

PR #3의 작은 정렬 구조와 해석 가능한 출력은 유지하되, 미래 fixation을 차단한 조건에서도 무엇이 성능을 만드는지 드러나게 합니다.

Recommended architecture

Causal Streaming Grounder

현재 모델의 cross-attention과 splat head는 유지하되, phrase가 완성된 시점 이전의 fixation만 key bank에 넣습니다. 먼저 모델 재학습 없이 causal replay로 성능 손실과 필요한 look-back horizon을 확인합니다.

1Output clockfinding phrase가 완성되는 t₀ 고정
→
2Causal key bankfixation_end ≤ t₀만 attention 후보
→
3Existing query–key공간 descriptor와 fixation key 정렬
→
4Splat + latencyheatmap·confidence·응답시간 출력
Module A

Causal replay부터

모든 단어마다 위치를 예측하지 않고 pathology mention이나 공간 구절이 완성될 때만 grounding합니다.

  • 현재 모델을 고정하고 mention 이후 fixation만 제거
  • 0.5/1/2/4초 look-back horizon 비교
  • full-sequence 결과를 oracle upper reference로 보존
Module B

Incremental key cache

하나의 최적 lag를 고르지 않고 여러 과거 구간에 attention을 분배합니다.

  • 새 fixation이 들어올 때 key를 append
  • query가 들어올 때 single-layer attention 한 번
  • 전체 sequence 재계산 없이 latency 측정
Module C

Image–behavior fusion gate

RadZero와 Final의 per-instance 오류가 다를 때만 image heatmap 결합을 진행합니다.

  • error correlation과 oracle max ceiling 계산
  • calibrated average·max·product baseline
  • gain이 있을 때만 작은 reliability gate 학습
Module D

보류할 수 있는 출력

gaze와 language가 충돌하거나 근거가 약하면 억지로 병변을 표시하지 않습니다.

  • attention entropy와 modality agreement로 confidence 구성
  • 근거가 약하거나 두 heatmap이 충돌하면 abstain
  • risk–coverage와 latency–coverage를 함께 보고
가장 먼저 확인할 ceiling

실제 병변과 겹치는 fixation만 oracle로 골랐을 때도 IoU가 낮다면, alignment 모델보다 gaze 자체의 공간 해상도와 ellipse 차이가 병목입니다. 이 경우 복잡한 모델을 키우기 전에 task를 point/containment 중심으로 재정의해야 합니다.

분할과 통계

  • 동일 subject_id·dicom_id가 train/test를 넘지 않는 patient/image group split
  • 3–5개 patient split과 leave-one-reader-out을 분리해 확인
  • 동일 instance에 대한 paired Wilcoxon과 metric에 맞는 effect size
  • 질환, 병변 크기, certainty, 판독자별 subgroup 결과

완료 기준

  • B1·RadZero·Temporal·Final·두 control을 한 run/instance set에서 유지
  • IoU와 Pointing을 함께 보고 masking metric asymmetry를 숨기지 않음
  • threshold sweep 경계 hit와 per-instance join key를 assertion으로 확인
  • causal replay와 fusion oracle ceiling 뒤에만 새 architecture 확대

Failure modes

좋은 점수처럼 보이는 다른 이유들

멀티모달 정렬에서는 모델 구조보다 시간 누출, 좌표 변환, 언어 shortcut이 결과를 더 크게 만들 수 있습니다.

R1 · Temporal leakage

미래 시선을 사용함

offline 전체 record를 입력하면 아직 말하지 않은 뒤쪽 gaze가 정답을 알려줄 수 있습니다.

Guardrail · causal mask + timestamp assertion
R2 · Coordinate mismatch

screen과 image 좌표가 어긋남

zoom, pan, windowing 시 원시 화면 좌표를 영상 pixel로 착각하면 overlay가 조용히 틀어집니다.

Guardrail · viewport inverse mapping + visual audit
R3 · Text shortcut

“right”만으로 위치를 맞힘

gaze 없이도 방향 단어가 큰 영역을 제한합니다. 개선을 gaze 효과로 잘못 읽을 수 있습니다.

Guardrail · language-only + gaze-shuffled baseline
R4 · Reader memorization

개인 lag 패턴을 외움

같은 판독자가 양쪽 split에 있으면 일반적 alignment가 아니라 reader style을 기억할 수 있습니다.

Guardrail · reader-held-out supplementary test
