01 · Problem

Looking at an error is not the same as wanting to edit it.

Image editing begins before a mouse click or text instruction. A person inspects the result, compares it with an internal goal, detects a mismatch, and decides whether that mismatch is worth changing. Gaze makes part of this hidden process observable, but it does not reveal the entire decision.

fixation≠noticed issue≠dissatisfaction≠edit intention≠edit instruction

A face, bright object, textual element, or unusual artifact may attract gaze even when the viewer likes it. Conversely, a global style mismatch may motivate revision without creating one concentrated fixation cluster. The research question must therefore stay narrow:

Primary question After accounting for what the image and task would normally attract, does gaze collected before any editing action predict the region a user later chooses to revise?
Operational reference

Revision intent is anchored to later behavior: keep/edit choice, selected region, reason, instruction, and accepted output. Gaze supplies evidence about intent; it is never the intent label by itself.

02 · Gaze foundations

Eye tracking turns a stream of samples into a sequence of viewing events.

An eye tracker estimates where the eyes intersect the display many times per second. Raw samples are noisy and contain gaps around blinks. An event detector groups relatively stable samples into fixations and faster transitions into saccades.

Fixation

A relatively stable look

Often summarized by center, start time, end time, and duration. It indicates overt visual attention near a region, not a command or guaranteed conscious recognition.

Saccade

A rapid movement between looks

Its path helps describe search order. Visual intake is commonly modeled around fixations, while the eyes are comparatively insensitive during the movement.

Dwell

Accumulated time in a region

May include several fixations and revisits. Longer dwell can reflect difficulty, interest, uncertainty, verification, or task importance.

Scanpath

The ordered viewing sequence

Preserves search, comparison, and return behavior that a static heatmap discards.

A heatmap is useful for visualization, but it collapses order. The model should retain fixation timing, first-entry time, revisit count, late dwell, dispersion, and transitions between candidate regions.

Calibration sets the spatial resolution.

A 1° visual-angle error can cover many pixels on a desktop display. Region labels and evaluation tolerances should be defined in degrees of visual angle or calibrated image coordinates—not chosen after seeing model scores.

Separate the hidden construct from its observable traces.

“Edit intent” is latent: it cannot be read directly from the eye tracker. A valid study triangulates it from several events and preserves disagreement among them.

Region reference

What was selected?

Brush mask, box, click point, or automatically proposed region corrected by the participant.

Reason reference

Why revise it?

Prompt violation, rendering artifact, relational error, style preference, or global dissatisfaction.

Instruction reference

What change was requested?

Add, remove, replace, move, recolor, reshape, restyle, or regenerate globally.

Outcome reference

Was the change accepted?

Acceptance distinguishes an intended edit from an exploratory action that did not satisfy the user.

04 · Confounds

Visual saliency is the first alternative explanation.

Saliency describes which regions attract attention across viewers because of stimulus properties such as contrast, faces, size, isolation, or composition. If an edit region is also highly salient, gaze–edit overlap does not by itself show intention.

observed viewer gaze−expected image-driven attention=candidate task residual

The residual is not automatically “intent.” It is the part not explained by a no-user saliency model and must still be compared with task relevance, prompt–image mismatch, object size, center bias, and interaction history.

Stimulus control

Saliency-only predictor

Estimates edit regions using the image without participant behavior.

Task control

Prompt–image grounding

Estimates regions inconsistent with the prompt, even if the user never looked there.

Geometry control

Center and size prior

Tests whether large central objects explain both gaze and selections.

Behavior control

Shuffled viewer or trial

Breaks the true gaze–action pairing while preserving aggregate gaze statistics.

Causal caution

Gaze may precede a decision, result from an already formed decision, or participate in comparing alternatives. Prediction is possible without identifying which causal role is true.

Study 1 · Identifiability

Establish the signal before building assistance.

Participants inspect a generated image without visible region proposals. Gaze is collected before the first edit action; later actions provide the reference.

  1. 1
    Present a prompt–image pair.

    Balance error type, spatial extent, object size, salience, and image quality. Include satisfactory images so the task does not imply that every image must be edited.

  2. 2
    Record unconstrained inspection.

    Keep the first viewing interval free of overlays. Synchronize gaze, image display, prompt visibility, and every UI event.

  3. 3
    Collect the decision.

    Ask keep/edit, then region, reason, confidence, and instruction. Preserve “global edit” and “unsure” rather than forcing a local mask.

  4. 4
    Generate and choose outcomes.

    Record accepted result, rejected attempts, manual corrections, and whether the original image was ultimately preferred.

06 · Evaluation

Measure localization, decision quality, and generalization separately.

Region quality

IoU · point hit · center distance

No one metric fits local masks, click points, and global edits. Report results by reference type and region size.

Intent decision

Precision · recall · AUPRC

Keep trials create a no-edit class. Precision matters because false prompts interrupt users.

Selective quality

Risk–coverage curve

As the system abstains more, does error fall enough to justify fewer suggestions?

Calibration

ECE · Brier score

A 0.8 confidence should correspond to comparable success rates if it controls UI behavior.

Unseen participant

Can gaze dynamics transfer to a new user?

Unseen image

Can the model avoid memorizing stimulus-specific saliency?

Unseen generator

Does it transfer to a different artifact distribution?

Participant and image identities must be grouped in the split. A trial-level random split can place nearly identical behavior or the same stimulus on both sides and inflate the result.

Direction and decisions

Current work belongs to the measurement layer.

The project is in study-design state. There are no empirical performance claims yet. The immediate product is a defensible construct, stimulus set, instrumentation plan, and preregistered model ladder.

Define

Stimulus taxonomy

Prompt violation, rendering artifact, relation error, and preference mismatch × local, relational, and global extent × salient and non-salient presentation.

Instrument

Behavioral reference

Synchronize gaze with keep/edit, selected region, reason, instruction, corrections, and accepted result.

Baseline

No-user explanations

Freeze saliency, geometry, and prompt-grounding baselines before participant data influence modeling decisions.

Gate

Identifiability threshold

Proceed to assistance only if precision, calibration, and participant/image generalization meet predefined criteria.

Working research questionWhich pre-action gaze dynamics predict a user’s later edit region beyond image saliency and task mismatch, and can calibrated proposals reduce articulation effort without reducing control?
