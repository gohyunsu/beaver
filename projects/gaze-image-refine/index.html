01 · Question

Looking at an error is not the same as wanting to edit it.

A generated image can attract gaze because an object is visually salient, surprising, malformed, important to the task, or simply pleasing. Only some of those cases lead to a revision.

observed fixation≠noticed problem≠edit intention≠desired edit

The project therefore asks a narrower question: after accounting for what the image would normally attract, does pre-action gaze predict the region a user later chooses to edit?

Operational definition

Edit intention is anchored to later behavior: keep/edit choice, selected region, stated reason, revision instruction, and accepted output. Gaze alone is never treated as ground truth.

Foundations

Three concepts define the measurement problem.

Visual saliency

What attracts many viewers

Contrast, faces, large objects, and composition can explain gaze without any dissatisfaction. A saliency-only model is a required baseline.

Midas touch

Looking is not commanding

A gaze-controlled system produces false activations when every inspection is interpreted as intent. Gaze should propose candidates, not execute edits.

Selective prediction

Act only at useful confidence

The system should abstain when gaze is diffuse or ambiguous and expose the trade-off between coverage and false interruption.

observed gaze−expected attention from the image=candidate intent residual

Study design

Prove identifiability before building assistance.

Study 1

Can revision intent be identified?

Collect gaze before any action, then record keep/edit, region, reason, revision instruction, and output choice. Compare gaze with visual saliency and prompt–image mismatch.

  • Leave-participant-out evaluation
  • Leave-image-out evaluation
  • Precision and risk–coverage, not accuracy alone
  • Error type × size × salience analysis
evidence gate
Study 2

Does a suggestion reduce articulation cost?

Compare manual region specification with a gaze-assisted preview that appears only at high confidence and always requires confirmation.

  • Time to first valid edit
  • Accepted suggestion and false interruption rates
  • Correction quality and number of revisions
  • Control, workload, and annoyance

03 · Literature

The closest work narrows the contribution.

These works make “edit an image with gaze” too broad as a novelty claim. The specific contribution must be passive, saliency-controlled identification of revision intent and the value of selective assistance that avoids false interruption.

Direction and progress

Current work belongs to the measurement layer.

The project is in study-design state. The immediate output is a defensible task and baseline suite, not an automated editor.

Define

Stimulus taxonomy

Prompt violation, rendering artifact, and preference mismatch × local, relational, and global extent × salient and non-salient presentation.

Instrument

Behavioral reference

Connect gaze to keep/edit, region, reason, instruction, and accepted result with synchronized events.

Baseline

No-user explanations

Prepare saliency-only and prompt-grounding predictors before participant data influence modeling choices.

Gate

Identifiability threshold

Proceed to interface assistance only if calibrated precision and participant/image generalization are sufficient.

Working research question When visual saliency and prompt–image mismatch are controlled, which gaze dynamics predict a user’s later edit region, and can high-confidence suggestions reduce articulation effort without reducing control?
