Decision

결론: 조건부로 적절합니다.

독립 관리 원칙

이 페이지의 상태·일정·task는 GazeMed·GazeImageRefine·leXic의 진행률과 합산하지 않습니다. 팀이 참가를 결정하고 HG-00 gate를 통과한 경우에만 Opportunity Lab 안에서 Active로 바뀝니다.

행사 분야·일정·협업 구조와는 잘 맞지만, 현재 BEAVER의 주 연구를 그대로 출품할 수 있는 상태는 아닙니다. 가장 타당한 연결은 gaze 모델의 로봇 전용 전환이 아니라, 과거 agent oversight 아이디어를 embodied agent의 작업 검증 문제로 확장하는 것입니다.

Go 조건

7월 매칭 단계에서 xArm/ROS 경험과 장비 접근성을 가진 파트너를 확보하고, 8월 계획서 전에 SDK 또는 시뮬레이터에서 한 개 작업의 observation–action logging과 emergency stop을 재현할 수 있을 때 참여를 권고합니다.

No-go 조건

파트너 없이 BEAVER가 로봇 제어·데이터 수집·VLA 학습까지 모두 맡아야 하거나, “범용 산업 안전을 보장하는 VLA”를 목표로 해야 한다면 범위를 줄이거나 참여하지 않는 편이 낫습니다.

중요한 경계

VLM/VLA 기반 semantic monitor는 “안전 보증”이 아니라 이상 징후 탐지기입니다. 물리적 collision avoidance와 emergency stop을 학습 모델의 confidence에 맡기지 않습니다.

Minimum viable demonstration

한 작업, 네 오류, 두 계층

넓은 제조 환경이 아니라 색상 블록 pick-and-place 셀 하나에서 반복 가능한 정상·오류 episode를 만듭니다.

Nominal

자연어 작업

“빨간 블록을 A 구역으로 옮겨줘.” 장면 인식, 접근, grasp, 이동, place의 진행을 표시합니다.

Semantic anomalies

잘못된 수행

wrong object, wrong destination, progress stall/grasp failure를 주입하고 monitor가 근거와 함께 감지합니다.

Physical hazards

즉시 차단

금지구역 진입·사람/장애물 접근은 hard rule과 controller stop으로 차단하고 semantic 경고와 구분합니다.

시나리오탐지 신호시스템 반응성공 기준

Evaluation

시연이 아니라 비교 가능한 실험으로 만듭니다.

필수 비교군

  1. no monitor: policy/controller만 실행
  2. rule-only: deterministic state·timeout 규칙
  3. semantic-only: vision/language 기반 이상 점수
  4. hybrid: semantic monitor + hard safety shield

핵심 지표

  • anomaly macro-F1/AUPRC, 정상 episode false-alarm rate
  • 위험 시작부터 탐지·정지까지의 latency
  • task success, unsafe success, intervention recovery success
  • 평균 완료 시간과 불필요한 pause 횟수

일반화

같은 episode frame을 무작위 분할하지 않습니다. object instance, 배치, 조명, 명령 paraphrase 중 최소 하나를 hold-out해 “기억”과 “전이”를 분리합니다.

Application-ready framing

추천서에는 이렇게 좁혀 씁니다.

주제

VLA 기반 로봇 작업의 명령–관측–행동 정합성 검증 및 이상행동 시각화 시스템

현장 문제

제조·물류 협동로봇은 자연어 지시를 이해하더라도 잘못된 객체 선택, 작업 정체, 목적지 오류처럼 task success만으로는 드러나지 않는 실패를 낼 수 있다. 운영자는 로봇이 무엇을 보고 어떤 근거로 행동했는지 확인하기 어렵다.

필요성 · 150자 이내 초안

자연어 기반 로봇은 잘못된 객체 선택·작업 정체·경로 위험을 성공 여부만으로 설명하기 어렵다. 명령–관측–행동을 실시간 대조해 이상을 조기 탐지하고 근거를 시각화하는 검증 계층이 필요하다.

앵커팀 협업계획 초안

우리 팀의 멀티모달 정렬·이상탐지·평가 역량과 부산 공유대학 팀의 로봇 제어·현장 시나리오·센서 통합 역량을 결합한다. 공통 event schema를 기준으로 AI monitor와 xArm 제어계를 독립 개발한 뒤, 실제 작업 episode에서 통합 검증한다.
