REFLACX audit

학습 전에 끝내야 할 무결성 검사

공식 스펙을 아는 것과 팀이 내려받은 파일이 실제로 연결되는 것은 다릅니다. 모델보다 먼저 reproducible manifest를 만듭니다.

01

Identity graph

reading ID → image ID → study ID → subject ID를 연결하고 중복과 split leakage를 검출.

02

Coordinate integrity

screen-to-image 변환, zoom/pan/window state, chest box normalization을 시각 표본으로 검증.

03

Signal quality

invalid sample 비율, fixation 수·지속시간, pupil missingness, recording duration 분포.

04

Label ecology

phase별 label vocabulary, 0–5 certainty, ellipse count, class imbalance, multi-reader subset.

Data manifest output

원본 파일을 복사하지 않고, 각 reading의 경로·checksum·shape·quality flags·split만 담은 manifest와 audit report를 version control합니다.

Label semantics

전문가 라벨도 불확실성을 갖습니다.

REFLACX의 certainty 0은 “radiologist가 선택하지 않음”이고, 1–5는 unlikely에서 consistent with까지의 확신도입니다. 이를 단일 binary truth로 바꾸려면 threshold가 필요하며, threshold에 따라 positive case와 class balance가 바뀝니다.

  • 주 분석 threshold를 사전 정의하고 ≥3, ≥4, =5 등 sensitivity analysis를 함께 보고합니다.
  • 같은 이미지의 multi-reader subset에서는 agreement와 label variability를 분석합니다.
  • ellipse는 병변의 정밀 경계라기보다 localized reference region으로 취급합니다.
  • negative label의 gaze를 “병변을 안 봄”으로 해석하지 않습니다. 정상 확인 과정도 여러 해부 구조를 봅니다.

접근·보안 원칙

  • MIMIC 계열 데이터는 DUA에 따라 승인된 사용자·환경에서만 사용하고 재배포하지 않습니다.
  • Git에는 raw image, gaze, report, participant record를 올리지 않습니다.
  • 코드는 환경 변수나 로컬 manifest를 통해 데이터 경로를 받고, 실제 계정·서버 경로를 문서에 고정하지 않습니다.
  • GazeImageRefine 참가자 데이터는 동의서 범위 안에서만 사용하며 eye video를 불필요하게 보존하지 않습니다.
  • 논문 재현을 위해 공개 가능한 preprocessing code, synthetic fixture, schema, split ID 또는 생성 규칙을 제공합니다.
