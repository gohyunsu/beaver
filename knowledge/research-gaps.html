Gap grammar

“아무도 안 했다”보다 무엇이 비어 있는가.

연구 공백은 서로 다른 문제를 포함합니다. 종류를 구분해야 논문 추가 조사, ablation, 새 데이터 수집 중 무엇이 필요한지 결정할 수 있습니다.

Validity

현재 결론을 흔드는 설명

split, leakage, metric, label noise 때문에 같은 결과가 나올 수 있는지 묻습니다.

해결 · audit, control, resampling

Mechanism

시간, 위치, 언어, 모델 용량 중 실제 기여를 분리하지 못한 상태입니다.

해결 · targeted ablation

Generalization

어디까지 유지되는가

다른 환자 split, 판독자, 기관, 장비에서도 결과가 유지되는지 열려 있습니다.

해결 · group-held-out evaluation

System

실제 흐름에서 작동하는가

offline metric이 latency, interruption, calibration을 포함한 사용 장면으로 이어지는지 묻습니다.

해결 · causal prototype, user workflow
Novelty gap과 evidence gap은 다릅니다.

새 모델을 제안할 수 있는 빈칸보다, 현재 주장을 믿기 위해 반드시 메워야 하는 validity gap이 먼저입니다. 후자는 논문 기여가 작아 보여도 연구 전체의 신뢰도를 결정합니다.

GazeMed · evidence boundary

관찰된 것과 아직 말할 수 없는 것

PR #3의 2026년 7월 29일 technical spec 기준입니다. 모든 수치는 같은 patient-level split의 1,093개 test instance에서 측정됐습니다.

Observed

직접 측정된 결과

  • Final IoU 0.3188, Pointing 0.7237
  • Temporal-only 대비 두 지표 모두 개선, 5/5 training seed 유지
  • position shuffle 시 IoU 0.2101, Pointing 0.4337로 붕괴
  • spatial-word mask 시 IoU는 5/5 seed 저하, Pointing 유의성은 2/5 seed
  • RadZero 대비 IoU 우세, Pointing은 통계적 동률
Supported

현재 지지되는 주장

  • 위치·언어를 결합한 gaze attention은 시간 정렬만 쓸 때보다 낫습니다.
  • 효과는 실제 fixation과 위치의 instance-level 대응에 의존합니다.
  • 공간 단어는 region overlap에 작지만 반복되는 기여를 보입니다.
  • 영상 없이 gaze+speech만으로 image-text 모델과 경쟁 가능한 localization을 만듭니다.
Open

아직 지지되지 않은 주장

  • 발화 시점 이후의 gaze를 배제한 실시간 causal 성능
  • 다른 patient split과 unseen reader에서의 안정성
  • image와 gaze+speech가 서로의 오류를 실제로 보완한다는 주장
  • regex mention linker보다 임상 NLP 정렬이 유의하게 낫다는 주장
  • 다른 기관·장비·gaze dataset으로의 일반화

Idea 01 · highest upside

영상과 행동 신호를 경쟁시키지 않고 결합합니다.

RadZero는 image+phrase를, GazeMed Final은 gaze+speech를 봅니다. 서로 다른 정보원이므로 평균 순위보다 같은 사례에서의 오류 상보성이 먼저입니다.

Hypothesis 영상 근거가 강할 때는 RadZero를, 판독자의 실제 탐색이 더 구체적일 때는 gaze–speech를 신뢰하면 단일 modality보다 나은 localization이 가능하다.

Idea 02 · strongest system claim

“test-time”을 진짜 real-time으로.

현재 모델의 signed Δt는 mention 이후 fixation도 표현할 수 있습니다. 온라인 보조 시스템을 주장하려면 출력 시점보다 미래의 관찰을 명시적으로 차단해야 합니다.

past gazephrase complete · t₀future gaze

모델 입력은 fixation_end ≤ t₀인 사건으로 제한합니다. phrase가 끝나는 순간마다 현재까지의 fixation bank에서 localization을 갱신합니다.

Step 1

Causal replay evaluator

모델을 바꾸지 않고 record를 시간순으로 replay합니다.

  • sentence/phrase 종료 시각을 output clock으로 사용
  • 미래 fixation hard mask
  • 0.5/1/2/4초 look-back horizon sweep
Step 2

Incremental attention cache

새 fixation이 들어올 때 key만 추가해 전체 sequence를 다시 계산하지 않습니다.

  • CXR image를 쓰면 patch feature 1회 cache
  • fixation key append-only buffer
  • phrase query가 들어올 때 attention 1회
Step 3

Latency-aware output

정확도뿐 아니라 언제 표시할 수 있는지를 측정합니다.

  • mention end→heatmap latency
  • time-to-first-hit
  • confidence가 낮을 때 abstain
Step 4

Online controls

실시간 주장을 흔드는 shortcut을 차단합니다.

  • future-gaze positive control
  • fixed 1.5초 causal B1
  • phrase timestamp jitter curve
