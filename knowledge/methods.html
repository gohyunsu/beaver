GazeMed candidates

추천은 event token + shuffle ablation

Raw video branch는 중복과 비용이 크며 예비결과도 약했습니다. 작은 sequence encoder와 통제 ablation이 현재 질문에 더 직접적입니다.

Recommended

Event-token fusion

각 fixation을 (x, y, duration, Δt, optional pupil) token으로 만들고 corresponding image patch feature와 결합합니다. Transformer/LSTM 규모를 작게 유지합니다.

Recommended

Label-aligned heatmap

timestamped dictation에서 pathology mention을 찾고 observation–speech lag window 안 gaze만 모아 class-specific map을 만듭니다.

Deprioritized

Dense video tensor

1,000 Hz point stream을 frame stack으로 만들면 sparse tensor와 시간 중복이 큽니다. event branch가 raw 정보의 이점을 보일 때만 재검토합니다.

Baseline

Heatmap regularization

image classifier의 attention/CAM과 gaze heatmap을 alignment loss로 맞춥니다. 단순하고 강한 비교군입니다.

Too broad now

Generative medical VLM

report generation·VQA·grounding을 동시에 수행하는 방향은 GazeX·Gaze2Report와 경쟁하며 현재 일정과 데이터 규모에 비해 넓습니다.

Analysis

Temporal state discovery

scan/discover/verify/report phase를 먼저 명명하지 말고 HMM/change-point 또는 speech anchors로 탐색한 뒤 재현성을 확인합니다.

GazeImageRefine candidates

attention에서 intent를 잔차화합니다.

오래 본 영역을 곧바로 수정하면 Midas touch가 발생합니다. stimulus saliency와 task context를 baseline으로 먼저 설명하고 남은 gaze 신호를 사용합니다.

Region representation

pixel heatmap보다 object/part masks를 기본 단위로 사용해 Tobii의 spatial error와 edit operation을 정렬합니다.

Temporal feature

late dwell, revisit, regression, prompt↔image transition은 단순 first fixation보다 deliberation을 더 잘 나타낼 수 있습니다.

Selective prediction

coverage를 낮추더라도 calibrated confidence가 높은 trial만 제안해 false interruption을 줄입니다. risk–coverage curve를 보고합니다.

Evaluation discipline

평균 점수보다 일반화 구조

시선 데이터는 참가자·자극·trial이 중첩된 계층 자료입니다. 개별 sample을 독립 관측으로 다루면 신뢰구간이 과도하게 좁아집니다.

Split

Group isolation

환자/이미지/독자 또는 participant/image를 split 단위로 분리합니다.

Uncertainty

Hierarchical CI

seed variance와 sample bootstrap을 구분하고 paired interval을 보고합니다.

Calibration

Probability quality

AUROC 외 AUPRC, Brier, ECE와 selective risk를 봅니다.

Multiplicity

Primary outcome

가설과 1차 지표를 먼저 고정하고 탐색 분석은 구분합니다.

Signal quality

전처리 자체가 실험 조건입니다.

좌표와 장면

  • screen coordinate를 image coordinate로 옮길 때 viewport, aspect ratio, zoom, pan, window state를 반영합니다.
  • 화면 밖 gaze와 tracker loss를 구분하고, 좌표 clipping으로 문제를 숨기지 않습니다.
  • center bias와 해부학적 정상 확인 패턴을 random baseline보다 강한 baseline으로 둡니다.

Fixation parsing

  • REFLACX의 EyeLink parser threshold를 기록하고 다른 parser를 쓸 경우 sensitivity analysis를 합니다.
  • raw sample downsampling은 anti-aliasing/aggregation 원칙을 문서화합니다.
  • 짧은 fixation 제거, blink interpolation, smoothing이 label과 독립적으로 정해졌는지 확인합니다.

Pupil과 생체 해석

  • pupil area는 조명, 화면 밝기, 개인차, blink에 민감합니다. baseline normalization 없이 인지부하로 해석하지 않습니다.
  • EEG·GSR·HRV는 현재 핵심 질문에 필요한지부터 검증합니다. 센서를 늘리는 것은 contribution이 아닙니다.
